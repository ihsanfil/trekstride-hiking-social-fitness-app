TrekStride Hızlı Kurulum

  1. Node 20+, JDK 17+, Android Studio/SDK kur.
  2. api/TrekStride.Api: dotnet restore sonra dotnet run --urls http://0.0.0.0:5080.
  3. mobile: npm install.
  4. Android emulator açıkken npx react-native run-android.
  5. Fiziksel cihazda API adresini bilgisayarın LAN IP'sine çevir.
  6. Firebase/Adapty entegrasyonu hesap açıldıktan sonra etkinleştirilebilir; demo bunlar olmadan çalışır.

Fotoğraf depolama yok: maliyet sıfır, ana veri .NET API + SQL Server.
